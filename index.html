ПОЛИТИКА КОНФИДЕНЦИАЛЬНОСТИ приложения «Лила: Познай Себя»

1. Общие положения

1.1. Настоящая Политика конфиденциальности (далее — Политика) определяет порядок обработки и защиты информации о пользователях мобильного приложения «Лила» (далее — Приложение), которое доступно для установки из магазина приложений RuStore.

1.2. Настоящая Политика вступает в силу с момента публикации. Если пользователь не согласен с условиями, он должен прекратить использование Приложения и удалить его.

2. Оператор персональных данных

2.1. По всем вопросам, связанным с обработкой персональных данных, пользователь может обратиться к Оператору по указанному адресу электронной почты: Wotmb1kola@gmail.com.

3. Какие данные обрабатывает Приложение

3.1. Приложение не требует регистрации и не запрашивает у пользователя персональные данные (ФИО, адрес, телефон, контакты и т. д.).

3.2. При использовании Приложения автоматически обрабатываются следующие данные:

  • рекламный идентификатор устройства (GAID для Android / IDFA для iOS);
  • технические данные об устройстве: модель, версия операционной системы, разрешение экрана, язык устройства;
  • IP-адрес и страна (регион), определяемые по IP-адресу;
  • данные о показах рекламы и взаимодействии с ней (просмотры, клики).

3.3. Обработка указанных данных осуществляется через рекламный программный модуль Yandex Mobile Ads SDK, предоставляемый ООО «ЯНДЕКС». Приложение не собирает обезличенную статистику через сторонние сервисы аналитики.

3.4. Приложение не запрашивает доступ к камере, микрофону, контактам, файловой системе и точному местоположению (GPS). Страна определяется по IP-адресу и используется только для подбора рекламного контента.

4. Цели обработки данных

  • показ рекламы в Приложении, в том числе персонализированной (с учётом рекламного идентификатора устройства);
  • обеспечение корректной работы Приложения, выявление и устранение ошибок и сбоев.

5.1. Данные, указанные в разделе 3, передаются ООО «ЯНДЕКС» (сервис Yandex Mobile Ads) и обрабатываются в соответствии с политикой конфиденциальности Яндекса: https://yandex.ru/legal/confidential/

5.2. ООО «ЯНДЕКС» может передавать данные своим партнёрам — рекламным сетям и рекламодателям — в целях показа рекламы. Оператор не продаёт и не передаёт данные пользователей иным третьим лицам, за исключением случаев, предусмотренных законодательством.

6. Сроки хранения и защита данных

6.1. Данные обрабатываются в течение срока использования Приложения. Технические данные для работы SDK обрабатываются в рамках сервиса-партнёра; дополнительные копии на серверах Оператора не создаются.

6.2. Оператор принимает необходимые организационные и технические меры для защиты данных от неправомерного доступа, изменения, раскрытия или уничтожения.

7.1. Приложение не предназначено для сбора данных от лиц младше 6 лет. В Приложении отсутствует механизм регистрации и сбора данных детей.

8.1. Оператор вправе изменять Политику. Новая редакция вступает в силу с момента её публикации. Актуальная версия доступна по адресу, указанному в карточке Приложения в RuStore.
